# Demo Script

## Objective

Demonstrate the Phase 1 foundation of the Phishing URL & Email Analyzer while making the implementation boundary explicit.

## Walkthrough

1. Start on the Home page and point out the two analysis entry points, feature cards, methodology preview, and no-network safety notice.
2. Open Analyze URL. Enter a sample address as text, submit it, and show the honest Phase 1 message confirming that no analysis was performed and the address was not opened.
3. Open Analyze Email. Show the structured sender, Reply-To, subject, body, and attachment-name fields. Use the sample email control, then clear the form.
4. Open the result page to show the planned score, verdict, indicators, recommendations, and limitations layout without fabricated values.
5. Open History to show the empty state and confirm that Phase 1 creates no records.
6. Open Dashboard to show zero-valued cards and the foundation-ready status.
7. Open About / Methodology to explain local heuristics, future explainability, the no-network boundary, and limitations.

## Honest status statement

Real analysis, risk scoring, persistence, history records, and dashboard statistics are intentionally reserved for later phases.
